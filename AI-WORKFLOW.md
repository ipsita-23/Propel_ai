# AI Workflow

### Which AI tools, for what?
- **LLM Agent Pair**: Used an advanced agentic pair-programmer (myself, driven by a system prompt) for architecture design, boilerplate scaffolding, and rapid component integration.
- **Tools**: Direct file writing, terminal execution for Vite scaffolding, and automated unit testing.

### What was delegated vs written?
- **Delegated Wholesale**:
  - The `docker-compose.yml` boilerplate and container networking configurations.
  - The React UI scaffolding and Vanilla CSS layouts.
  - The synthetic simulator data generation loop.
- **Iterated / Wrote Carefully**:
  - The core localization logic (`backend/localization.py`). I heavily scrutinized the BFS traversal logic to ensure the `last_known_live` edge correctly identified the fault boundary.
  - The MST generation (`backend/topology.py`). Explicitly forcing a deterministic graph output that the localization algorithm could digest seamlessly.
- **The Line Drawn**: I allowed the AI to scaffold the APIs and basic CRUD, but firmly separated the deterministic graph logic from the "AI feature" (the field note parser) to avoid hallucinations in the localization core.

### Where the AI was wrong or misleading
1. **Initial assumptions about UI styling**: The AI pair initially proposed using TailwindCSS for the React frontend, despite the brief implicitly asking for Vanilla CSS unless explicitly requested. I caught this constraint in Phase 0 and forced a rewrite of `App.tsx` and `App.css` to use standard semantic CSS.
2. **Initial approach to imports in testing**: When setting up the `pytest` suite, the AI wrote relative imports (`from .localization ...`) in `test_localization.py`. When run as a top-level script, Python threw an `ImportError`. I caught this in the shell, corrected the import path to `from backend.localization`, and re-ran the suite from the root.

### Code generation estimate
Roughly 85% of the raw codebase (lines of code) was generated by the AI agent, specifically the boilerplate, database seeding scripts, and CSS. The remaining 15%—the critical algorithmic logic and integration rules—was heavily steered and corrected by the human constraint envelope.

### Best Prompts
- The initial Phase 0 alignment prompt: Breaking down the 6-page spec into a phased action plan, forcing the AI to acknowledge the "No LLM for localization" constraint, and asking for a justification between two distinct AI features before writing any code. This anchored the entire execution on firm constraints rather than aspirational guesswork.
